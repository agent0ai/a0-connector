# Constraints DOX

## Purpose

- Own generated release dependency lock files.

## Ownership

- `a0-runtime.txt` and `a0-build.txt` are generated by `devtools/lock_dependencies.py`.
- Dependency intent belongs in `requirements/`.

## Local Contracts

- Do not hand-edit lock files for normal dependency changes. Edit `requirements/*.in`, then regenerate.
- Keep hashes and generated metadata intact.
- When locks change, ensure `pyproject.toml` pins were synced by the lock script.

## Work Guidance

- Treat lock diffs as generated artifacts: review for unexpected packages, platform markers, or major version jumps.
- If an emergency manual edit is unavoidable, document why in the task closeout and follow up by regenerating.

## Verification

- With `uv` available: `./.venv/bin/python devtools/lock_dependencies.py --check`

## Child DOX Index

No child DOX files.
